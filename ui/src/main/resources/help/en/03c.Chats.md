# Chats

Chat rooms are multi-user rooms for chatting, a bit like [IRC](https://en.wikipedia.org/wiki/IRC).

The list of rooms appears in the listview on the left. Once you join one, you can chat in it, and you will make it available to your friends as well.

There are two kinds of chat rooms:

- 🌍 public: no restrictions
- 🔒 private: only visible to invited members

## Creation

Press the create chat room button 💬 on the top left, you will be able to supply the following fields:

- name: the name of the room. Choose it wisely as it cannot be changed afterwards
- the topic of the room: cannot be changed afterwards either
- visibility: public or private
- security: check if you want to avoid possible spam. Only identities signed by a profile will be allowed in. It's easier to trace them in case of abuse

## Joining a public chat room

On the left listview, there's a list of chat rooms relayed by your friends in the *Public* tree. Double click one or use the context menu to join it.

## Chatting

Just type to chat or press `shift + enter` to write in multiple lines. You can use [markdown](05a), send or paste images inline 🖼️, send a link 🖇️ to a file or send stickers.

## Private chat rooms

Private chat rooms are only available to people that are invited in it. You can create one, then use the *invite friend* button to invite one of your friend. A requester will show up if you're invited to a private room. All the rest is identical to public rooms.
