# Forums

Forums are public message boards similar to [newsgroups](https://en.wikipedia.org/wiki/Usenet_newsgroup).

The forums are synchronized with your friends. You can even write a message while being offline, and it will be synchronized later when your connection is restored.

## Creation

Press the create forum button 📁 on the top left, you will be able to supply the following fields:

- name: the name of the forum. Choose a descriptive name, but no worries, you can edit it afterwards.
- description: the description of the forum. You can edit it afterwards.

## Subscribing to a forum

Just browse the *Popular* or *Other* tree on the left and double-click or use the context menu on the forum you're interested to join. It can take a while to synchronize, depending on your connectivity.

## Posting a message

You can post a message by using the *create message* button ✏️. Messages require a subject and a body text, which is written using [markdown](05a).

You can reply to a message by selecting it in the list and selecting *Reply* in the context menu.

You can also edit your own message, but keep in mind that the previous version might still be available to some other users.
