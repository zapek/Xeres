# Channels

Channels are a way to distribute information and files. Only the creator of the channel can post.

## Creation

Press the create channel button 📁 on the top left, you will be able to supply the following fields:

- name: the name of the channel. Choose a descriptive name, but no worries, you can edit it afterwards.
- description: the description of the channel. You can edit it afterwards.
- logo: a picture for your channel. You can change it afterwards.

## Subscribing to a channel

Just browse the *Popular* or *Other* tree on the left and double-click or use the context menu on the channel you're interested to join. It can take a while to synchronize, depending on your connectivity.

## Posting a message

First, remember you can only post on your own channel. To do so, use the *create message* button ✏️. A channel post requires:

- title: the title of your post
- thumbnail: a thumbnail that shows up near the title
- body text: optionally, a text, like a blog post or description
- files: one or several files that can be downloaded by users reading the post
