# Boards

Boards are a way to post images and links, similar to online message boards.

Unlike channels, boards can be posted to by anyone.

## Creation

Press the create board button 📁 on the top left, you will be able to supply the following fields:

- name: the name of the board. Choose a descriptive name, but no worries, you can edit it afterwards.
- description: the description of the board. You can edit it afterwards.
- logo: a picture for your board. You can change it afterwards.

## Subscribing to a board

Just browse the *Popular* or *Other* tree on the left and double-click or use the context menu on the board you're interested to join. It can take a while to synchronize, depending on your connectivity.

## Posting a message

Use the *create message* button ✏️. A board post requires:

- title: the title of your post
- body text: a text, like a blog post or description
- image: the image of the post. The resolution is sufficient in most cases.
- link: a link to some website or internal content

Only the title is required. All the rest is optional. For example, you can post a single link, a link with a description, a single image, an image with a description and a link, etc...
