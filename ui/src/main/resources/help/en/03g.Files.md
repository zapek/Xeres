# Files

Files allows to share, search, upload and download files. The system uses the [Turtle protocol](https://en.wikipedia.org/wiki/Turtle_F2F) which means all file operations are anonymous. They will also go beyond your direct friends and a download can use multiple sources.

The tab on the left side allows to select the following sections:

## Search

To search, enter one or several search terms. All of them have to match the resulting file for it to be displayed. For example searching for *foo* and *bar* will return *foobar* and *barfoo* but not *foo*.

💡 To find an exact match, use quotes around your search terms, for example "foo bar" will match *foo bar* but not *bar foo*.

To download a file, use the context menu over a result and select *download*.

## Downloads

The download tab displays the ongoing downloads and their progress. It can take a while, depending on the speed of the sources, how many of them are available as well as your link speed. Once a file is marked as *Done*, use the context menu to act upon it.

## Uploads

Displays the files that you're currently uploading.

## Trends

Displays all the searches that are hitting your node.
