# Settings

This window contains the various settings of Xeres.

- [General](04a): theme, update check, auto startup, remember credentials
- [Notifications](04b): show connections, broadcast and LAN discovery
- [Network](04c): NAT, LAN, DHT, UPNP
- [Transfer](04d): incoming directory
- [Media](04e): link preview, external URL confirmation
- [Sound](04f): sound for various events
- [Remote](04g): remote access
