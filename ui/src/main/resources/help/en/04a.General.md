# General

## Theme

Sets a theme for the app, either a light one or a dark one depending on your preferences, eyesight, screen and so on.

## System

### Automatically check for updates

This checks the GitHub API of the Xeres project once a day to see if there's a new release.

🛡️ [Privacy implications](07a)

### Remember credentials

If supported, the OS will be used to remember the credentials to securely decrypt the data. No password prompt will show up. Very useful when *Launch on system startup* is enabled.

🛡️ [Privacy implications](07h)

### Launch on system startup

Automatically launches Xeres when the user logs in. This is currently only implemented on a normal Windows installation.
