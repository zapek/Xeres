# Media

## Enable link preview

Enables a small link preview (thumbnail + description) of most incoming links from friends marked as fully trusted.

🚨 Be careful because the link preview is generated on your side!

🛡️ [Privacy implications](07f)

This feature only works in private chats (direct, not distant) and only with friends that have their trust level marked as *full* (default is *unknown*).

Default is off. Enable it if you trust your *full* friends, prefer seeing a preview, and end up clicking on most of their links anyway.

## Enable external URL confirmation

When enabled, a requester will ask for confirmation before opening external websites. This is the default.

🛡️ [Privacy implications](07g)
