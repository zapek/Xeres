# Stickers

Stickers are small images or animations that help express emotions. They can be sent in chat messages.

## Adding stickers

Sticker collections go into subdirectories, for example:

- `01.People`
- `02.Places`

The 01, 02, etc... optional prefix allows to control the order in which the sticker collections appear in the list.

Each collection contains various stickers, for example for the `01.People` directory:

- `01.Heike.png`
- `02.Juergen.png`
- `03.Antilove.png`

And so on. They also can have optional prefix for ordering, but a name like `Heike.png` only is fine, too.

## File formats

The following file formats are supported:

### Images

- JPEG, up to 512x512 pixels (`*.jpg`)
- PNG, up to 512x512 pixels, supporting transparency (`*.png`)
- WebP, up to 512x512 pixels, supporting transparency (`*.webp`)

### Animations

- TGS (`*.tgs`)
- Lottie (`*.lottie`, `*.json`)
