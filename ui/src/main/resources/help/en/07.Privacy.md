# Privacy

This part is for privacy conscious people. It contains all technicalities about features that can expose you on the Internet and help you make an informed decision.

- [Updates](07a): automatic update checks
- [UPNP](07b): to redirect incoming ports
- [External DNS](07c): using external DNS services to find one's IP address
- [LAN Discovery](07d): broadcasting presence on the LAN
- [DHT](07e): finding friends
- [Link Preview](07f): showing URLs
- [External URL](07g): external URLs warnings
