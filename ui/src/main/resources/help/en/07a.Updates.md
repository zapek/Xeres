# Check for updates

## Details

A connection is performed to `https://api.github.com/repos/zapek/Xeres/releases/latest` using a generic *Chrome on Windows* user-agent to avoid tracking.

The version gathered is compared locally and, if there's a newer release, an option to download it is offered. If accepted, the file and its signature are downloaded from GitHub using the same mechanism. Before installation, a signature verification is performed using the built-in public key from the running
application. If everything is fine, the update can be installed.

The check is performed daily (with a skew, to make profiling harder).

## Risks

🟢 Low

GitHub might know (but not for certain) that you're using Xeres.
