# UPNP

## Details

Xeres tries to use UPNP to do two things:

- get the external IP
- open an incoming port

The second feature will leave a connection entry on the router, which will point to the IP of your machine. If you're the owner of the router, this is fine.

## Risks

🟢 Low on your own network

🟡 Medium on a public network

It is recommended to enable it on your own home network and disable it on public networks. Public networks rarely have UPNP working anyway, but they might learn that you're running Xeres.
