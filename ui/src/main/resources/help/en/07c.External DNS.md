# Using external DNS

## Details

Xeres will try to use a random external DNS from [OpenDNS](https://en.wikipedia.org/wiki/OpenDNS) or [Akamai](https://en.wikipedia.org/wiki/Akamai_Technologies). It will send a UDP packet to their DNS servers in order to try to resolve the external IP (`myip.opendns.com` and `whoami.akamai.net`).

## Risks

🟢 Low

These services will know you want to find out your public IP, but this is done by many other applications as well as they provide that service exactly for that purpose. The mechanism being similar as normal resolvers, there's no way for them to know that you're using Xeres.
