# LAN Discovery

## Details

LAN Discovery periodically sends a UDP broadcast packet to find out if other Xeres clients are on the LAN. It implements the same protocol as found in the [udp-discovery-cpp](https://github.com/truvorskameikin/udp-discovery-cpp) project.

The following information is broadcast:

- a Xeres application identifier
- your IP address and port
- your profile fingerprint
- your location identifier
- your profile name

The data is used to update a friend's IP on the LAN to be able to connect to them if it changed (for example a DHCP lease that expired). If enabled in the Notifications settings, it can also display that someone is available on the LAN.

## Risks

🟢 Low on your own network 🟠 High on a public network

It is recommended to enable it on your own home network and disable it on public networks. Public networks might learn that you're running Xeres and will also know your profile's name.
