# Remember credentials

## Details

When enabled, the OS will be used to store the database password's credentials so that prompting for the profile password is not needed. Note that the password of your profile is not stored, only the one of the database.

This currently only works on Windows using the [Data Protection API](https://en.wikipedia.org/wiki/Data_Protection_API) (or DPAPI). The database's password will be encrypted using your Windows account credentials. If the Xeres data is moved to another machine or your Windows account is removed, decryption will fail.

## Risks

🟢 Low

The OS encryption API is designed for encrypting sensitive data. This defers the security to your OS account, which means it should have a strong password. A malware running under your user's account can potentially decrypt the password.
