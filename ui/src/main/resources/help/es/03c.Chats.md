# Chats

Las salas de chat son salas multiusuario para chatear, un poco como [IRC](https://en.wikipedia.org/wiki/IRC).

La lista de salas aparece en la vista de lista de la izquierda. Una vez que te unas a una, podrás chatear en ella, y también la pondrás a disposición de tus amigos.

Hay dos tipos de salas de chat:

- 🌍 pública: sin restricciones
- 🔒 privada: solo visible para los miembros invitados

## Creación

Pulsa el botón de crear sala de chat 💬 en la parte superior izquierda; podrás rellenar los siguientes campos:

- nombre: el nombre de la sala. Elígelo con criterio, ya que no se puede cambiar después
- el tema de la sala: tampoco se puede cambiar después
- visibilidad: pública o privada
- seguridad: marca esta casilla si quieres evitar un posible spam. Solo se permitirán identidades firmadas por un perfil. Es más fácil rastrearlas en caso de abuso

## Unirse a una sala de chat pública

En la vista de lista de la izquierda hay una lista de salas de chat retransmitidas por tus amigos en el árbol *Público*. Haz doble clic en una o usa el menú contextual para unirte.

## Chatear

Solo escribe para chatear o pulsa `shift + enter` para escribir en varias líneas. Puedes usar [markdown](05a), enviar o pegar imágenes en línea 🖼️, enviar un enlace 🖇️ a un archivo o enviar pegatinas.

## Salas de chat privadas

Las salas de chat privadas solo están disponibles para las personas invitadas a ellas. Puedes crear una y luego usar el botón *invitar amigo* para invitar a uno de tus amigos. Aparecerá un aviso si te invitan a una sala privada. Todo lo demás es idéntico a las salas públicas.
