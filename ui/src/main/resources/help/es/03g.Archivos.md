# Archivos

Archivos permite compartir, buscar, subir y descargar archivos. El sistema usa el [protocolo Turtle](https://en.wikipedia.org/wiki/Turtle_F2F), lo que significa que todas las operaciones con archivos son anónimas. También van más allá de tus amigos directos y una descarga puede usar múltiples fuentes.

La pestaña del lado izquierdo permite seleccionar las siguientes secciones:

## Búsqueda

Para buscar, introduce uno o varios términos de búsqueda. Todos ellos deben coincidir con el archivo resultante para que se muestre. Por ejemplo, buscar *foo* y *bar* devolverá *foobar* y *barfoo*, pero no *foo*.

💡 Para encontrar una coincidencia exacta, usa comillas alrededor de tus términos de búsqueda; por ejemplo, "foo bar" coincidirá con *foo bar*, pero no con *bar foo*.

Para descargar un archivo, usa el menú contextual sobre un resultado y selecciona *descargar*.

## Descargas

La pestaña de descargas muestra las descargas en curso y su progreso. Puede tardar un tiempo, según la velocidad de las fuentes, cuántas están disponibles y tu velocidad de enlace. Una vez que un archivo se marca como *Completado*, usa el menú contextual para actuar sobre él.

## Subidas

Muestra los archivos que estás subiendo actualmente.

## Tendencias

Muestra todas las búsquedas que llegan a tu nodo.
