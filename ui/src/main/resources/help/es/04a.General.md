# General

## Tema

Establece un tema para la aplicación, ya sea claro u oscuro, según tus preferencias, vista, pantalla, etc.

## Sistema

### Comprobar actualizaciones automáticamente

Esto consulta la API de GitHub del proyecto Xeres una vez al día para ver si hay una nueva versión.

🛡️ [Implicaciones de privacidad](07a)

### Recordar credenciales

Si es compatible, el sistema operativo se usará para recordar las credenciales y descifrar los datos de forma segura. No aparecerá ninguna solicitud de contraseña. Muy útil cuando está activado *Iniciar al arrancar el sistema*.

🛡️ [Implicaciones de privacidad](07h)

### Iniciar al arrancar el sistema

Inicia Xeres automáticamente cuando el usuario inicia sesión. Actualmente solo está implementado en una instalación normal de Windows.
