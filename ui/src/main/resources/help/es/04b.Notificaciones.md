# Notificaciones

Muestra una notificación del sistema para los siguientes eventos:

### Mostrar conexiones

Siempre que se establece una conexión con un amigo.

### Mostrar difusiones

Siempre que un amigo envía un mensaje de difusión, que es un mensaje enviado a todos sus amigos. Estos mensajes suelen enviarse para eventos importantes, como anunciar una caída prolongada o un problema.

Desafortunadamente también se puede abusar de ello, por lo que a veces es deseable desactivarlos.

### Mostrar descubrimiento

Siempre que alguien está en la LAN y tiene activado el descubrimiento LAN. Tú también debes tenerlo activado.
