# Red

## NAT

NAT significa [traducción de direcciones de red](https://en.wikipedia.org/wiki/Network_address_translation). Es el sistema que permite que muchos dispositivos detrás de tu router accedan a Internet usando la única dirección IP pública de tu router. El problema con el NAT es que las conexiones entrantes no funcionan sin
ayuda.

### IP y puerto externos

Aquí deberían mostrarse la IP y el puerto externos, en caso de que se hayan detectado correctamente.

### Usar UPNP

[Universal Plug and Play (UPNP)](https://en.wikipedia.org/wiki/Universal_Plug_and_Play) es un software que se ejecuta en tu router. Si está activado, Xeres intentará usarlo para mejorar las conexiones entrantes de tus amigos.

Se recomienda activarlo cuando estés en tu propia red privada (en casa), y desactivarlo en caso contrario. En Windows, si está establecido en *Privado* (el valor predeterminado), se activará automáticamente si tu red usa un perfil privado
(consulta [cómo establecer un perfil privado en Windows](https://search.brave.com/search?q=how+to+set+a+network+profile+on+windows)). En otras plataformas, *Privado* estará desactivado por defecto.

Aunque el UPNP adquirió mala reputación debido a algunos errores tempranos, si tu router es lo bastante reciente, puedes activarlo allí con seguridad.

#### Recurso alternativo a DNS externo

Si está marcado y el UPNP falla al obtener la IP externa, Xeres intentará usar un DNS público aleatorio para obtenerla en su lugar.

## LAN

LAN significa [red de área local](https://en.wikipedia.org/wiki/Local_area_network). Tu propia red detrás de tu router.

### IP y puerto internos

Aquí se muestran la IP y el puerto internos.

### Usar descubrimiento LAN

El descubrimiento LAN es un sistema para encontrar a otros usuarios en la red local. Ayudará a actualizar las IP de los amigos en la LAN para poder conectarse a ellos si han cambiado (por ejemplo, una concesión DHCP expirada).

Si está activado en los ajustes de Notificaciones, también puede mostrar que alguien está disponible en la LAN.

Dado que la información podría ser sensible, se recomienda activarlo solo cuando estés en tu propia red privada (en casa), y desactivarlo en caso contrario. En Windows, si está establecido en *Privado* (el valor predeterminado), se activará automáticamente si tu red usa un perfil privado
(consulta [cómo establecer un perfil privado en Windows](https://search.brave.com/search?q=how+to+set+a+network+profile+on+windows)). En otras plataformas, *Privado* estará desactivado por defecto. Podría haber otros escenarios donde activarlo sea útil (por ejemplo, una fiesta LAN).

## DHT

La [tabla hash distribuida](https://en.wikipedia.org/wiki/Distributed_hash_table) es un sistema que ayuda a dos pares a encontrarse cuando su dirección IP ha cambiado o es desconocida. Es útil especialmente en un entorno dinámico (itinerancia, dirección IP dinámica, ...)

### Activar DHT

Activa o desactiva la DHT.

Cuándo activar la DHT:

- tienes una dirección IP que cambia con frecuencia
- usas un portátil y te desplazas/viajas mucho
- tienes muchos amigos que también tienen esos hábitos

Cuándo no activar la DHT:

- tienes una dirección IP fija/estable y un UPNP que funciona
- tienes un ancho de banda muy limitado
- quieres pasar desapercibido. La DHT enviará paquetes a muchos pares

Por defecto, está desactivada.

## Servicios ocultos

Este ajuste solo sirve para poder conectarse a clientes Retroshare que usan servicios ocultos ([Tor](https://en.wikipedia.org/wiki/Tor) o [I2P](https://en.wikipedia.org/wiki/I2P)). Xeres en sí no implementa ningún tipo de servicio oculto, por lo que esto no anonimizará nada.

Si quieres conectarte a usuarios de Tor o I2P, configura el proxy socks de Tor/I2P según corresponda para apuntar a tu instalación de Tor/I2P en ejecución.
