# Sonido

Este ajuste permite producir sonido en algunos eventos. Simplemente selecciona un archivo de sonido corto para cada evento.

Formatos multimedia compatibles:

- MP3
- MP4 (AAC)
- WAV
- AIFF

## Mensaje recibido

Cuando se recibe un mensaje privado directo o a distancia. Mientras la ventana tiene el foco y está activa, no se producen nuevos sonidos.

## Menciones

Cuando alguien te menciona en un chat de sala.

## Amigo conectado

Cuando un amigo se conecta a tu instancia en ejecución.

## Descarga completada

Cuando se completa una descarga.

## Llamada

Cuando alguien te llama con VoIP.
