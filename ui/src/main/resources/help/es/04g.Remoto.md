# Remoto

Este ajuste permite conectarse a una instancia de Xeres en ejecución usando un cliente remoto (ya sea otro Xeres en modo de cliente remoto o el [cliente para Android](https://github.com/zapek/Xeres-Android/)).

La conexión está cifrada (TLS 1.3 con un certificado autofirmado). El cliente de Android admite el anclaje de certificados (certificate pinning), que es muy recomendable para evitar ataques de intermediario (man in the middle).

## Activado

Activa o desactiva la función.

## Puerto

El puerto que se usará para las conexiones entrantes. Deberá ser accesible desde tu router.

## Configurar con UPNP

Usa UPNP para enrutar el puerto en tu router. El UPNP debe estar activado en los ajustes de Red.

## Nombre de usuario

Este es el nombre de usuario predeterminado, no se puede cambiar.

## Contraseña

La contraseña. Aunque puedes usar una contraseña vacía (para pruebas o conexiones locales), no se recomienda hacerlo. Por defecto se genera una contraseña segura que rara vez necesita cambiarse.
