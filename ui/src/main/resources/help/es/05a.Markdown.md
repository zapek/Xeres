# Markdown

Aquí tienes una chuleta de Markdown:

## Sintaxis básica

Markdown es compatible en foros y chats (aunque en estos últimos se ignoran los encabezados y las reglas horizontales).

### Encabezado

\# Header 1

\## Header 2

\### Header 3

(up to Header 6)

### Negrita

\*\*bold\*\* or \_\_bold\_\_

### Cursiva

\*italic\* or \_italic\_

### Cita

\> blockquote

### Lista ordenada

1. First item
2. Second item
3. Third item

### Lista desordenada

\- First item \- Second item \- Third item

### Código

\`code`

### Regla horizontal

\---

### Enlace

\[Markdown Guide](https://www.markdownguide.org)

### Imagen

\![alt text]\(data:image/jpeg;base64,etc...)

## Sintaxis extendida

### Bloque de código delimitado

\`\`\` {
"firstName": "John",
"lastName": "Smith",
"age": 25 } \`\`\`

### Tachado

\~~Censored~~
