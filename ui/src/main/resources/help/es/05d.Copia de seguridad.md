# Copia de seguridad de tus datos

Todos los datos que usa Xeres se almacenan localmente, por lo que deberías hacer una copia de seguridad de vez en cuando.

Aquí está la ubicación de la carpeta de la que debes hacer una copia de seguridad:

- Windows: `%APPDATA%\Xeres`
- Linux: `$HOME/.local/share/Xeres`
- macOS: `/Users/username/Library/Application Support/Xeres`
