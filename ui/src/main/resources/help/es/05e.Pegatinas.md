# Pegatinas

Las pegatinas son imágenes pequeñas o animaciones que ayudan a expresar emociones. Se pueden enviar en mensajes de chat.

## Agregar pegatinas

Las colecciones de pegatinas van en subdirectorios, por ejemplo:

- `01.People`
- `02.Places`

El prefijo opcional 01, 02, etc... permite controlar el orden en el que las colecciones de pegatinas aparecen en la lista.

Cada colección contiene varias pegatinas, por ejemplo para el directorio `01.People`:

- `01.Heike.png`
- `02.Juergen.png`
- `03.Antilove.png`

Y así sucesivamente. También pueden tener un prefijo opcional para el orden, pero un nombre como `Heike.png` solamente también está bien.

## Formatos de archivo

Se admiten los siguientes formatos de archivo:

### Imágenes

- JPEG, hasta 512x512 píxeles (`*.jpg`)
- PNG, hasta 512x512 píxeles, con soporte de transparencia (`*.png`)
- WebP, hasta 512x512 píxeles, con soporte de transparencia (`*.webp`)

### Animaciones

- TGS (`*.tgs`)
- Lottie (`*.lottie`, `*.json`)
