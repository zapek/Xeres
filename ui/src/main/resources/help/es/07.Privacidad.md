# Privacidad

Esta parte es para personas concienciadas con la privacidad. Contiene todos los detalles técnicos sobre las funciones que pueden exponerte en Internet y te ayuda a tomar una decisión informada.

- [Actualizaciones](07a): comprobación automática de actualizaciones
- [UPNP](07b): para redirigir puertos entrantes
- [DNS externo](07c): uso de servicios DNS externos para encontrar la dirección IP de uno
- [Descubrimiento LAN](07d): difusión de la presencia en la LAN
- [DHT](07e): encontrar amigos
- [Vista previa de enlaces](07f): mostrar URL
- [URL externa](07g): avisos de URL externas
- [Recordar credenciales](07h): no pedir la contraseña al iniciar
