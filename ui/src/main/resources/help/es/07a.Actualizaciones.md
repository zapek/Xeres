# Comprobar actualizaciones

## Detalles

Se realiza una conexión a `https://api.github.com/repos/zapek/Xeres/releases/latest` usando un user-agent genérico de *Chrome en Windows* para evitar el seguimiento.

La versión obtenida se compara localmente y, si hay una versión más reciente, se ofrece la opción de descargarla. Si se acepta, el archivo y su firma se descargan de GitHub usando el mismo mecanismo. Antes de la instalación, se realiza una verificación de la firma usando la clave pública integrada de la aplicación en
ejecución. Si todo es correcto, se puede instalar la actualización.

La comprobación se realiza a diario (con una variación aleatoria, para dificultar la elaboración de perfiles).

## Riesgos

🟢 Bajo

GitHub podría saber (aunque no con certeza) que estás usando Xeres.
