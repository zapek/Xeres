# UPNP

## Detalles

Xeres intenta usar UPNP para hacer dos cosas:

- obtener la IP externa
- abrir un puerto entrante

La segunda función dejará una entrada de conexión en el router, que apuntará a la IP de tu máquina. Si eres el propietario del router, esto no supone un problema.

## Riesgos

🟢 Bajo en tu propia red

🟡 Medio en una red pública

Se recomienda activarlo en tu propia red doméstica y desactivarlo en redes públicas. Las redes públicas rara vez tienen UPNP funcionando de todos modos, pero podrían saber que estás ejecutando Xeres.
