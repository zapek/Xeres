# Uso de DNS externo

## Detalles

Xeres intentará usar un DNS externo aleatorio de [OpenDNS](https://en.wikipedia.org/wiki/OpenDNS) o [Akamai](https://en.wikipedia.org/wiki/Akamai_Technologies). Enviará un paquete UDP a sus servidores DNS para intentar resolver la IP externa (`myip.opendns.com` y `whoami.akamai.net`).

## Riesgos

🟢 Bajo

Estos servicios sabrán que quieres averiguar tu IP pública, pero muchos otros programas hacen lo mismo, ya que ofrecen ese servicio precisamente para ese propósito. Como el mecanismo es similar al de los resolvers normales, no hay forma de que sepan que estás usando Xeres.
