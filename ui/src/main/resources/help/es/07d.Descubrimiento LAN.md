# Descubrimiento LAN

## Detalles

El descubrimiento LAN envía periódicamente un paquete de difusión UDP para averiguar si hay otros clientes de Xeres en la LAN. Implementa el mismo protocolo que se encuentra en el proyecto [udp-discovery-cpp](https://github.com/truvorskameikin/udp-discovery-cpp).

Se difunde la siguiente información:

- un identificador de la aplicación Xeres
- tu dirección IP y puerto
- la huella de tu perfil
- tu identificador de ubicación
- el nombre de tu perfil

Los datos se usan para actualizar la IP de un amigo en la LAN y así poder conectarse a él si ha cambiado (por ejemplo, una concesión DHCP expirada). Si está activado en los ajustes de Notificaciones, también puede mostrar que alguien está disponible en la LAN.

## Riesgos

🟢 Bajo en tu propia red

🟠 Alto en una red pública

Se recomienda activarlo en tu propia red doméstica y desactivarlo en redes públicas. Las redes públicas podrían saber que estás ejecutando Xeres y también conocerán el nombre de tu perfil.
