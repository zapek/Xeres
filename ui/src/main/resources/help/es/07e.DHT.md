# DHT

## Detalles

Xeres usa la [Mainline DHT](https://en.wikipedia.org/wiki/Mainline_DHT), que es la DHT que usa [BitTorrent](https://en.wikipedia.org/wiki/BitTorrent). Enviará y recibirá periódicamente paquetes UDP con otros pares aleatorios para almacenar un hash de tu ID de ubicación. Otros amigos solicitarán ese ID y, con el tiempo,
te encontrarán. Ten en cuenta que tu dirección IP en sí nunca se almacena en la DHT.

## Riesgos

🟡 Medio

Aunque la propia DHT la usan millones de usuarios de torrents, lo que dificulta detectar así a los usuarios de Xeres, enviará paquetes UDP a muchos pares, lo que no es muy discreto.
