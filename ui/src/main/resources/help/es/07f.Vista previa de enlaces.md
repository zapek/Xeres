# Vista previa de enlaces

## Detalles

La vista previa del enlace se genera en tu lado; es decir, Xeres se conectará al sitio de terceros descrito por el enlace y obtendrá los datos de él. El sitio de terceros verá una conexión entrante tuya, incluso si no has hecho clic en el enlace. Se ha tenido especial cuidado en usar un user-agent "genérico" para
evitar que la detección de Xeres sea demasiado fácil.

## Riesgos

🟠 Alto

Aunque el sitio web de terceros tendrá dificultades para detectar que estás usando Xeres, pueden usarlo para crear un perfil relacionado con tu dirección IP, dependiendo de las URL que tus amigos te envíen.
