# Recordar credenciales

## Detalles

Cuando esté activado, el sistema operativo se usará para almacenar las credenciales de la contraseña de la base de datos, de modo que no sea necesario pedir la contraseña del perfil. Ten en cuenta que la contraseña de tu perfil no se almacena, solo la de la base de datos.

Actualmente esto solo funciona en Windows mediante la [API de protección de datos](https://en.wikipedia.org/wiki/Data_Protection_API) (o DPAPI). La contraseña de la base de datos se cifrará usando las credenciales de tu cuenta de Windows. Si los datos de Xeres se mueven a otra máquina o tu cuenta de Windows se elimina,
el descifrado fallará.

## Riesgos

🟢 Bajo

La API de cifrado del sistema operativo está diseñada para cifrar datos sensibles. Esto delega la seguridad en tu cuenta del sistema operativo, lo que significa que debe tener una contraseña segura. Un malware que se ejecute bajo tu cuenta de usuario podría descifrar la contraseña.
