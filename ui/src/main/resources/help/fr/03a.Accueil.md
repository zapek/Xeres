# Accueil

L'onglet d'accueil contient quelques informations succinctes.

Appuyez sur votre identifiant Xeres pour l'afficher sous forme de code QR, de chaîne de caractères, pour l'imprimer, etc.

Appuyez sur le bouton de copie pour copier votre identifiant Xeres dans le presse-papiers afin de pouvoir le partager avec vos amis.

Appuyez sur le bouton Ajouter pair pour ajouter un ami.
