# Contacts

Contient la liste de tous les contacts (identités et profils) connus de votre instance. Les contacts incluent vos amis directs mais aussi d'autres utilisateurs du réseau.

## Votre contact

En haut à gauche, vous pouvez cliquer sur votre propre contact et modifier votre photo en cliquant sur l'arrière-plan de la photo dans la vue des détails. Vous pouvez également définir votre statut en cliquant sur la LED ronde colorée.

Vous pouvez aussi changer votre mot de passe en cliquant sur l'icône de sécurité 🛡️.

## Autres contacts

La vue en liste contient les éléments suivants :

- des identités
- des profils
- des identités adossées à un profil

En général, elle essaie de fusionner ce qui peut l'être. Utilisez le filtre pour afficher tous les contacts ou uniquement vos amis.

### Niveau de confiance

Dans le panneau de détails, vous pouvez définir le niveau de confiance de vos amis :

- Inconnu : c'est la valeur par défaut.
- Jamais : c'est un ami en qui vous n'avez pas encore vraiment confiance.
- Marginal : plus ou moins digne de confiance. Une connaissance, quelqu'un que vous connaissez un peu.
- Total : entièrement digne de confiance, un bon ami.

Pour l'instant, les niveaux de confiance ont une fonctionnalité limitée. Par exemple, si l'[Aperçu des liens](04e) est activé, il ne s'appliquera qu'aux amis entièrement dignes de confiance.

### Localisations

Le tableau en bas affiche toutes les localisations connues d'un ami. S'il possède plusieurs appareils, vous les verrez listés ici.

### Opinion

Les identités obtiennent une réputation définie par vos amis. Vous pouvez la voir avec l'icône pouce vers le haut 👍 et pouce vers le bas 👎. Si une identité a plus d'opinions négatives que positives, elle perdra en visibilité.

Vous pouvez définir votre propre opinion sur les identités :

- 😑 Neutre : c'est la valeur par défaut.
- 👍 Positive : c'est la valeur définie par défaut pour vos amis et elle peut être utilisée si vous voulez qu'une identité contourne l'opinion de vos amis.
- 👎 Négative : cela bannira effectivement l'identité de votre réseau.

## Chat

Le menu contextuel sur une identité (ou le bouton de chat 💬 en haut à droite) permet de démarrer soit un chat direct, soit un chat distant.

### Chat direct

C'est le système de chat utilisé avec les amis auxquels vous êtes directement connecté. C'est généralement plus rapide.

### Chat distant

C'est le système de chat utilisé avec les identités qui ne sont pas des amis directs. Il utilise le système de tunnels Turtle et est donc plus lent, moins fiable mais totalement anonyme (c'est-à-dire que votre IP n'est pas exposée à l'autre partie).
