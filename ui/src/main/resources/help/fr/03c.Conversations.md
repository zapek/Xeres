# Conversations

Les salles de discussion sont des salles multi-utilisateurs pour discuter, un peu comme [IRC](https://en.wikipedia.org/wiki/IRC).

La liste des salles apparaît dans la vue en liste à gauche. Une fois que vous en rejoignez une, vous pouvez y discuter et vous la rendrez également disponible à vos amis.

Il existe deux types de salles de discussion :

- 🌍 publique : aucune restriction
- 🔒 privée : visible uniquement par les membres invités

## Création

Appuyez sur le bouton de création de salle de discussion 💬 en haut à gauche, vous pourrez alors fournir les champs suivants :

- nom : le nom de la salle. Choisissez-le judicieusement, car il ne peut pas être modifié ensuite
- le sujet de la salle : ne peut pas être modifié ensuite non plus
- visibilité : publique ou privée
- sécurité : cochez si vous voulez éviter d'éventuels spams. Seules les identités signées par un profil seront autorisées. Elles sont plus faciles à tracer en cas d'abus

## Rejoindre une salle de discussion publique

Dans la vue en liste de gauche, il y a une liste des salles de discussion relayées par vos amis dans l'arborescence *Public*. Double-cliquez dessus ou utilisez le menu contextuel pour la rejoindre.

## Discuter

Il suffit de taper pour discuter ou d'appuyer sur `shift + enter` pour écrire sur plusieurs lignes. Vous pouvez utiliser le [markdown](05a), envoyer ou coller des images en ligne 🖼️, envoyer un lien 🖇️ vers un fichier ou envoyer des autocollants.

## Salles de discussion privées

Les salles de discussion privées ne sont accessibles qu'aux personnes qui y sont invitées. Vous pouvez en créer une, puis utiliser le bouton *inviter un ami* pour inviter l'un de vos amis. Une demande apparaîtra si vous êtes invité dans une salle privée. Tout le reste est identique aux salles publiques.
