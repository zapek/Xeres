# Forums

Les forums sont des tableaux de messages publics similaires aux [groupes de discussion](https://en.wikipedia.org/wiki/Usenet_newsgroup).

Les forums sont synchronisés avec vos amis. Vous pouvez même écrire un message hors ligne, et il sera synchronisé plus tard lorsque votre connexion sera rétablie.

## Création

Appuyez sur le bouton de création de forum 📁 en haut à gauche, vous pourrez alors fournir les champs suivants :

- nom : le nom du forum. Choisissez un nom descriptif, mais pas d'inquiétude, vous pourrez le modifier ensuite.
- description : la description du forum. Vous pourrez la modifier ensuite.

## S'abonner à un forum

Parcourez simplement l'arborescence *Populaire* ou *Autre* à gauche et double-cliquez ou utilisez le menu contextuel sur le forum qui vous intéresse pour le rejoindre. La synchronisation peut prendre du temps, selon votre connectivité.

## Publier un message

Vous pouvez publier un message en utilisant le bouton *créer un message* ✏️. Les messages nécessitent un sujet et un corps de texte, rédigé à l'aide du [markdown](05a).

Vous pouvez répondre à un message en le sélectionnant dans la liste et en choisissant *Répondre* dans le menu contextuel.

Vous pouvez également modifier votre propre message, mais gardez à l'esprit que la version précédente pourrait encore être disponible pour certains autres utilisateurs.
