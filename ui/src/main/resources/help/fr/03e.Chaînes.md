# Chaînes

Les chaînes sont un moyen de distribuer des informations et des fichiers. Seul le créateur de la chaîne peut publier.

## Création

Appuyez sur le bouton de création de chaîne 📁 en haut à gauche, vous pourrez alors fournir les champs suivants :

- nom : le nom de la chaîne. Choisissez un nom descriptif, mais pas d'inquiétude, vous pourrez le modifier ensuite.
- description : la description de la chaîne. Vous pourrez la modifier ensuite.
- logo : une image pour votre chaîne. Vous pourrez la changer ensuite.

## S'abonner à une chaîne

Parcourez simplement l'arborescence *Populaire* ou *Autre* à gauche et double-cliquez ou utilisez le menu contextuel sur la chaîne qui vous intéresse pour la rejoindre. La synchronisation peut prendre du temps, selon votre connectivité.

## Publier un message

Tout d'abord, rappelez-vous que vous ne pouvez publier que sur votre propre chaîne. Pour ce faire, utilisez le bouton *créer un message* ✏️. Une publication de chaîne nécessite :

- titre : le titre de votre publication
- vignette : une vignette qui apparaît à côté du titre
- corps du texte : facultativement, un texte, comme un article de blog ou une description
- fichiers : un ou plusieurs fichiers pouvant être téléchargés par les utilisateurs lisant la publication
