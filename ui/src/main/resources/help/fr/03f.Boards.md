# Boards

Les boards sont un moyen de publier des images et des liens, similaires aux tableaux de messages en ligne.

Contrairement aux chaînes, n'importe qui peut publier dans les boards.

## Création

Appuyez sur le bouton de création de board 📁 en haut à gauche, vous pourrez alors fournir les champs suivants :

- nom : le nom du board. Choisissez un nom descriptif, mais pas d'inquiétude, vous pourrez le modifier ensuite.
- description : la description du board. Vous pourrez la modifier ensuite.
- logo : une image pour votre board. Vous pourrez la changer ensuite.

## S'abonner à un board

Parcourez simplement l'arborescence *Populaire* ou *Autre* à gauche et double-cliquez ou utilisez le menu contextuel sur le board qui vous intéresse pour le rejoindre. La synchronisation peut prendre du temps, selon votre connectivité.

## Publier un message

Utilisez le bouton *créer un message* ✏️. Une publication de board nécessite :

- titre : le titre de votre publication
- corps du texte : un texte, comme un article de blog ou une description
- image : l'image de la publication. La résolution est suffisante dans la plupart des cas.
- lien : un lien vers un site web ou un contenu interne

Seul le titre est obligatoire. Tout le reste est facultatif. Par exemple, vous pouvez publier un simple lien, un lien avec une description, une simple image, une image avec une description et un lien, etc.
