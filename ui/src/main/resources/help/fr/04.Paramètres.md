# Paramètres

Cette fenêtre contient les différents paramètres de Xeres.

- [Général](04a) : thème, vérification des mises à jour, démarrage automatique, mémorisation des identifiants
- [Notifications](04b) : afficher les connexions, les diffusions et la découverte LAN
- [Réseau](04c) : NAT, LAN, DHT, UPNP
- [Transfert](04d) : répertoire de réception
- [Médias](04e) : aperçu des liens, confirmation des URL externes
- [Son](04f) : son pour divers événements
- [Accès distant](04g) : accès distant
