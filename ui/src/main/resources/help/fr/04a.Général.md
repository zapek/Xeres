# Général

## Thème

Définit un thème pour l'application, soit clair, soit sombre, selon vos préférences, votre vue, votre écran, etc.

## Système

### Vérifier automatiquement les mises à jour

Cette option vérifie une fois par jour l'API GitHub du projet Xeres pour voir s'il existe une nouvelle version.

🛡️ [Implications en matière de vie privée](07a)

### Mémoriser les identifiants

Si cela est pris en charge, le système d'exploitation sera utilisé pour mémoriser les identifiants afin de déchiffrer les données en toute sécurité. Aucune invite de mot de passe ne s'affichera. Très utile lorsque *Lancer au démarrage du système* est activé.

🛡️ [Implications en matière de vie privée](07h)

### Lancer au démarrage du système

Lance automatiquement Xeres lorsque l'utilisateur se connecte. Ceci n'est actuellement implémenté que sur une installation Windows normale.
