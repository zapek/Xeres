# Notifications

Affiche une notification système pour les événements suivants :

### Afficher les connexions

Chaque fois qu'une connexion d'ami est établie.

### Afficher les diffusions

Chaque fois qu'un ami envoie un message de diffusion, c'est-à-dire un message envoyé à chacun de ses amis. Ces messages sont généralement envoyés pour des événements importants, comme l'annonce d'une indisponibilité durable ou d'un problème.

Malheureusement, cela peut aussi être abusé, il est donc parfois souhaitable de les désactiver.

### Afficher la découverte

Chaque fois que quelqu'un est sur le LAN et a activé la découverte LAN. Vous devez également l'avoir activée vous-même.
