# Réseau

## NAT

NAT signifie [Network Address Translation (traduction d'adresses réseau)](https://en.wikipedia.org/wiki/Network_address_translation). C'est le système qui permet à de nombreux appareils derrière votre routeur d'atteindre Internet en utilisant l'unique adresse IP publique de votre routeur. Le problème avec le NAT est
que les connexions entrantes ne fonctionnent pas sans une aide.

### Utiliser UPNP

[Universal Plug and Play (UPNP)](https://en.wikipedia.org/wiki/Universal_Plug_and_Play) est un logiciel qui s'exécute sur votre routeur. S'il est activé, Xeres essaiera de l'utiliser pour améliorer les connexions entrantes de vos amis.

Il est recommandé de l'activer sur votre propre réseau privé (à la maison), et de le désactiver sinon. Sous Windows, s'il est défini sur *Privé* (la valeur par défaut), il sera activé automatiquement si votre réseau utilise un profil privé
(voir [comment définir un profil privé sous Windows](https://search.brave.com/search?q=how+to+set+a+network+profile+on+windows)). Sur les autres plateformes, *Privé* sera défini par défaut sur *désactivé*.

Même si UPNP a acquis une mauvaise réputation à cause de quelques bugs précoces, si votre routeur est assez récent, vous pouvez l'activer en toute sécurité.

🛡️ [Implications en matière de vie privée](07b)

#### Repli sur le DNS externe

Si cette option est cochée, et si UPNP échoue à obtenir l'IP externe, Xeres essaiera d'utiliser un DNS public aléatoire pour l'obtenir à la place.

## LAN

LAN signifie [Local Area Network (réseau local)](https://en.wikipedia.org/wiki/Local_area_network). Votre propre réseau derrière votre routeur.

### IP et port internes

L'IP interne et le port sont affichés ici.

### Utiliser la découverte LAN

La découverte LAN est un système pour trouver d'autres utilisateurs sur le réseau local. Elle aidera à mettre à jour les IP des amis sur le LAN afin de pouvoir s'y connecter si elles ont changé (par exemple un bail DHCP expiré).

Si elle est activée dans les paramètres de notifications, elle peut également afficher que quelqu'un est disponible sur le LAN.

Comme l'information peut être sensible, il est recommandé de ne l'activer que sur votre propre réseau privé (à la maison), et de la désactiver sinon. Sous Windows, s'il est défini sur *Privé* (la valeur par défaut), il sera activé automatiquement si votre réseau utilise un profil privé
(voir [comment définir un profil privé sous Windows](https://search.brave.com/search?q=how+to+set+a+network+profile+on+windows)). Sur les autres plateformes, *Privé* sera défini par défaut sur *désactivé*. Il peut y avoir d'autres scénarios où l'activer peut être utile (par exemple une LAN party).

## DHT

La [table de hachage distribuée](https://en.wikipedia.org/wiki/Distributed_hash_table) est un système qui aide deux pairs à se trouver l'un l'autre lorsque leur adresse IP a changé ou est inconnue. Elle est particulièrement utile dans un environnement dynamique (itinérance, adresse IP dynamique, ...)

### Activer le DHT

Active ou désactive le DHT.

Quand activer le DHT :

- vous avez une adresse IP qui change fréquemment
- vous utilisez un ordinateur portable et vous vous déplacez/voyagez beaucoup
- vous avez beaucoup d'amis qui ont aussi ces habitudes

Quand ne pas activer le DHT :

- vous avez une adresse IP fixe/stable et un UPNP fonctionnel
- vous avez une bande passante très limitée
- vous voulez rester discret. Le DHT enverra des paquets à de nombreux pairs

Par défaut, il est désactivé.

## Services cachés

Ce paramètre sert uniquement à pouvoir se connecter aux clients Retroshare qui utilisent des services cachés ([Tor](https://en.wikipedia.org/wiki/Tor) ou [I2P](https://en.wikipedia.org/wiki/I2P)). Xeres lui-même n'implémente aucun type de service caché, donc cela n'anonymisera rien.

Si vous voulez vous connecter aux utilisateurs de Tor ou d'I2P, configurez respectivement le proxy socks Tor/I2P vers votre installation Tor/I2P en cours d'exécution.
