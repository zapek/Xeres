# Son

Ce paramètre permet de produire du son pour certains événements. Il suffit de sélectionner un court fichier sonore pour chaque événement.

Formats de médias pris en charge :

- MP3
- MP4 (AAC)
- WAV
- AIFF

## Message reçu

Lorsqu'un message privé direct ou distant est reçu. Tant que la fenêtre est au premier plan et active, aucun nouveau son n'est produit.

## Mention

Lorsque quelqu'un vous mentionne dans une salle de discussion.

## Ami connecté

Lorsqu'un ami se connecte à votre instance en cours d'exécution.

## Téléchargement terminé

Lorsqu'un téléchargement est terminé.

## Appel

Lorsque quelqu'un vous appelle en VoIP.
