# Accès distant

Ce paramètre permet de se connecter à une instance Xeres en cours d'exécution à l'aide d'un client distant (soit un autre Xeres en mode client distant, soit le [client Android](https://github.com/zapek/Xeres-Android/)).

La connexion est chiffrée (TLS 1.3 avec un certificat auto-signé). Le client Android prend en charge l'épinglage de certificat, ce qui est fortement recommandé pour éviter les attaques de l'homme du milieu.

## Activé

Active ou désactive la fonctionnalité.

## Port

Le port à utiliser pour les connexions entrantes. Il devra être accessible depuis votre routeur.

## Définir avec UPNP

Utilisez UPNP pour router le port sur votre routeur. UPNP doit être activé dans les paramètres Réseau.

## Nom d'utilisateur

C'est le nom d'utilisateur par défaut, il ne peut pas être modifié.

## Mot de passe

Le mot de passe. Bien que vous puissiez utiliser un mot de passe vide (pour les tests ou les connexions locales), ce n'est pas recommandé. Un mot de passe fort est généré par défaut et nécessite rarement d'être modifié.
