# Markdown

Voici une aide-mémoire Markdown :

## Syntaxe de base

Markdown est pris en charge dans les forums et les chats (ces derniers ignorent cependant les titres et les lignes horizontales).

### Titre

\# Header 1

\## Header 2

\### Header 3

(jusqu'au titre 6)

### Gras

\*\*bold\*\* ou \_\_bold\_\_

### Italique

\*italic\* ou \_italic\_

### Citation

\> blockquote

### Liste ordonnée

1. First item
2. Second item
3. Third item

### Liste non ordonnée

\- First item  
\- Second item  
\- Third item

### Code

\`code`

### Ligne horizontale

\---

### Lien

\[Markdown Guide](https://www.markdownguide.org)

### Image

\![alt text]\(data:image/jpeg;base64,etc...)

## Syntaxe étendue

### Bloc de code délimité

\`\`\`  
{  
"firstName": "John",  
"lastName": "Smith",  
"age": 25  
}  
\`\`\`

### Barré

\~~Censored~~
