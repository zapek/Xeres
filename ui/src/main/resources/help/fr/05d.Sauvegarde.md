# Sauvegarder vos données

Toutes les données utilisées par Xeres sont stockées localement, vous devriez donc les sauvegarder de temps en temps.

Voici l'emplacement du dossier que vous devez sauvegarder :

- Windows : `%APPDATA%\Xeres`
- Linux : `$HOME/.local/share/Xeres`
- macOS : `/Users/username/Library/Application Support/Xeres`
