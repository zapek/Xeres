# Stickers

Les stickers sont de petites images ou animations qui aident à exprimer des émotions. Ils peuvent être envoyés dans les messages de chat.

## Ajouter des stickers

Les collections de stickers vont dans des sous-répertoires, par exemple:

- `01.People`
- `02.Places`

Le préfixe optionnel 01, 02, etc... permet de contrôler l'ordre dans lequel les collections de stickers apparaissent dans la liste.

Chaque collection contient divers stickers, par exemple pour le répertoire `01.People`:

- `01.Heike.png`
- `02.Juergen.png`
- `03.Antilove.png`

Et ainsi de suite. Ils peuvent aussi avoir un préfixe optionnel pour l'ordre, mais un nom comme `Heike.png` seul convient aussi.

## Formats de fichier

Les formats de fichier suivants sont pris en charge:

### Images

- JPEG, jusqu'à 512x512 pixels (`*.jpg`)
- PNG, jusqu'à 512x512 pixels, avec support de la transparence (`*.png`)
- WebP, jusqu'à 512x512 pixels, avec support de la transparence (`*.webp`)

### Animations

- TGS (`*.tgs`)
- Lottie (`*.lottie`, `*.json`)
