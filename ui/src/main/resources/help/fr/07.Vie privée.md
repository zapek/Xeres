# Vie privée

Cette partie est destinée aux personnes soucieuses de leur vie privée. Elle contient tous les détails techniques sur les fonctionnalités qui peuvent vous exposer sur Internet et vous aide à prendre une décision éclairée.

- [Mises à jour](07a) : vérification automatique des mises à jour
- [UPNP](07b) : pour rediriger les ports entrants
- [DNS externe](07c) : utiliser des services DNS externes pour trouver son adresse IP
- [Découverte LAN](07d) : diffusion de la présence sur le LAN
- [DHT](07e) : trouver des amis
- [Aperçu des liens](07f) : affichage des URL
- [URL externe](07g) : avertissements pour les URL externes
- [Mémoriser les identifiants](07h) : ne pas demander le mot de passe au démarrage
