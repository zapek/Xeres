# Vérifier les mises à jour

## Détails

Une connexion est effectuée vers `https://api.github.com/repos/zapek/Xeres/releases/latest` en utilisant un user-agent générique *Chrome sous Windows* pour éviter le pistage.

La version obtenue est comparée localement et, s'il existe une version plus récente, une option pour la télécharger est proposée. Si elle est acceptée, le fichier et sa signature sont téléchargés depuis GitHub en utilisant le même mécanisme. Avant l'installation, une vérification de la signature est effectuée à l'aide
de la clé publique intégrée à l'application en cours d'exécution. Si tout est en ordre, la mise à jour peut être installée.

La vérification est effectuée quotidiennement (avec un décalage, pour rendre le profilage plus difficile).

## Risques

🟢 Faible

GitHub pourrait savoir (mais pas avec certitude) que vous utilisez Xeres.
