# UPNP

## Détails

Xeres essaie d'utiliser UPNP pour faire deux choses :

- obtenir l'IP externe
- ouvrir un port entrant

La deuxième fonctionnalité laissera une entrée de connexion sur le routeur, qui pointera vers l'adresse IP de votre machine. Si vous êtes le propriétaire du routeur, c'est sans problème.

## Risques

🟢 Faible sur votre propre réseau

🟡 Moyen sur un réseau public

Il est recommandé de l'activer sur votre propre réseau domestique et de le désactiver sur les réseaux publics. Les réseaux publics ont rarement UPNP fonctionnel de toute façon, mais ils pourraient apprendre que vous exécutez Xeres.
