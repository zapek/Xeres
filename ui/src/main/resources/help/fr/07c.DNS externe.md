# Utiliser un DNS externe

## Détails

Xeres essaiera d'utiliser un DNS externe aléatoire parmi [OpenDNS](https://en.wikipedia.org/wiki/OpenDNS) ou [Akamai](https://en.wikipedia.org/wiki/Akamai_Technologies). Il enverra un paquet UDP à leurs serveurs DNS afin d'essayer de résoudre l'IP externe (`myip.opendns.com` et `whoami.akamai.net`).

## Risques

🟢 Faible

Ces services sauront que vous voulez connaître votre IP publique, mais cela est fait par de nombreuses autres applications, car ils fournissent ce service précisément à cette fin. Le mécanisme étant similaire à celui des résolveurs normaux, il n'y a aucun moyen pour eux de savoir que vous utilisez Xeres.
