# Découverte LAN

## Détails

La découverte LAN envoie périodiquement un paquet de diffusion UDP pour savoir si d'autres clients Xeres sont sur le LAN. Elle implémente le même protocole que celui du projet [udp-discovery-cpp](https://github.com/truvorskameikin/udp-discovery-cpp).

Les informations suivantes sont diffusées :

- un identifiant d'application Xeres
- votre adresse IP et votre port
- l'empreinte de votre profil
- votre identifiant de localisation
- votre nom de profil

Les données sont utilisées pour mettre à jour l'IP d'un ami sur le LAN afin de pouvoir s'y connecter si elle a changé (par exemple un bail DHCP expiré). Si elle est activée dans les paramètres de notifications, elle peut également afficher que quelqu'un est disponible sur le LAN.

## Risques

🟢 Faible sur votre propre réseau

🟠 Élevé sur un réseau public

Il est recommandé de l'activer sur votre propre réseau domestique et de la désactiver sur les réseaux publics. Les réseaux publics pourraient apprendre que vous exécutez Xeres et connaîtront également le nom de votre profil.
