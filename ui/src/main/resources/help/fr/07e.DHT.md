# DHT

## Détails

Xeres utilise le [DHT Mainline](https://en.wikipedia.org/wiki/Mainline_DHT) qui est le DHT utilisé par [BitTorrent](https://en.wikipedia.org/wiki/BitTorrent). Il enverra et recevra périodiquement des paquets UDP avec d'autres pairs aléatoires pour stocker un hachage de votre ID de localisation. D'autres amis
demanderont cet ID et finiront par vous trouver. Notez que votre adresse IP elle-même n'est jamais stockée dans le DHT.

## Risques

🟡 Moyen

Bien que le DHT lui-même soit utilisé par des millions d'utilisateurs de torrents, ce qui rend difficile la détection des utilisateurs de Xeres de cette manière, il enverra des paquets UDP à de nombreux pairs, ce qui n'est pas très discret.
