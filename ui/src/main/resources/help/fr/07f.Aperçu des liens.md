# Aperçu des liens

## Détails

L'aperçu des liens est généré de votre côté, c'est-à-dire que Xeres se connectera au site tiers décrit par le lien et en récupérera les données. Le site tiers verra une connexion entrante de votre part, même si vous n'avez pas cliqué sur le lien. Un soin particulier a été apporté à l'utilisation d'un user-agent «
générique » afin de ne pas rendre la détection de Xeres trop facile.

## Risques

🟠 Élevé

Bien que le site web tiers aura des difficultés à détecter que vous utilisez Xeres, il peut l'utiliser pour construire un profil lié à votre adresse IP, selon les URL que vos amis vous donnent.
