# Confirmation d'URL externe

## Détails

Désactiver cette fonctionnalité ouvrira directement les URL externes par l'application configurée dans votre système d'exploitation (généralement votre navigateur web).

## Risques (de la désactiver)

🟠 Élevé

Xeres prend certaines mesures pour essayer de signaler les URL externes (avec une petite icône de lien) et l'infobulle que vous obtenez en survolant l'URL.

Il détectera également les URL malveillantes (protocoles non chiffrés et faux liens), les affichera en rouge et avertira à leur sujet.

Néanmoins, quelqu'un sur un chat public pourrait essayer, par exemple, d'exposer votre adresse IP en vous faisant cliquer sur un lien sur son propre serveur, c'est pourquoi vous devez être prudent lorsque vous désactivez cette fonctionnalité.
