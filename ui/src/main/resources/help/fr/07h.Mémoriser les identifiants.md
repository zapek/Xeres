# Mémoriser les identifiants

## Détails

Lorsque cette option est activée, le système d'exploitation sera utilisé pour stocker les identifiants du mot de passe de la base de données, de sorte qu'il ne soit pas nécessaire de demander le mot de passe du profil. Notez que le mot de passe de votre profil n'est pas stocké, seulement celui de la base de données.

Cela ne fonctionne actuellement que sous Windows via l'[API de protection des données](https://en.wikipedia.org/wiki/Data_Protection_API) (ou DPAPI). Le mot de passe de la base de données sera chiffré à l'aide des identifiants de votre compte Windows. Si les données de Xeres sont déplacées vers une autre machine ou si
votre compte Windows est supprimé, le déchiffrement échouera.

## Risques

🟢 Faible

L'API de chiffrement du système d'exploitation est conçue pour chiffrer des données sensibles. Cela délègue la sécurité à votre compte du système d'exploitation, ce qui signifie qu'il doit avoir un mot de passe fort. Un logiciel malveillant fonctionnant sous votre compte utilisateur pourrait potentiellement déchiffrer
le mot de passe.
