# Интерфейс

Xeres предлагает следующие функции, доступные через вкладки в верхней части окна.

- [Главная](03a): делитесь своим Xeres ID и добавляйте друзей
- [Контакты](03b): управляйте всеми контактами, доступными в вашей сети
- [Чат](03c): общайтесь в реальном времени в чат-комнатах
- [Форумы](03d): участвуйте в синхронизированных обсуждениях
- [Каналы](03e): публикуйте файлы, новости или записи в блоге в своём канале для подписчиков
- [Доски](03f): делитесь картинками и ссылками на досках
- [Файлы](03g): ищите, отправляйте и получайте файлы анонимно

## Строка состояния

В строке состояния внизу отображается количество подключений к вашим друзьям, а также другие индикаторы.

### Связь

Этот индикатор отображает качество вашей связи.

### DHT

Индикатор DHT появляется только в том случае, если DHT включён (см. [Настройки / Сеть](04c))
