# Главная

Вкладка «Главная» содержит краткую информацию.

Нажмите на свой Xeres ID, чтобы показать его в виде QR-кода, строки, для печати и т.д.

Нажмите кнопку копирования, чтобы скопировать ваш Xeres ID в буфер обмена и поделиться им с друзьями.

Нажмите кнопку «Добавить контакт», чтобы добавить друга.
