# Чаты

Чат-комнаты — это многопользовательские комнаты для общения, немного похожие на [IRC](https://en.wikipedia.org/wiki/IRC).

Список комнат отображается в списке слева. Как только вы присоединяетесь к комнате, вы можете общаться в ней, а также делаете её доступной для своих друзей.

Существует два вида чат-комнат:

- 🌍 публичные: без ограничений
- 🔒 приватные: видны только приглашённым участникам

## Создание

Нажмите кнопку создания чат-комнаты 💬 вверху слева — вы сможете заполнить следующие поля:

- имя: название комнаты. Выбирайте его с умом, так как его нельзя изменить впоследствии
- тема комнаты: её также нельзя изменить впоследствии
- видимость: публичная или приватная
- безопасность: отметьте, если хотите избежать возможного спама. В комнату будут допускаться только личности, подписанные профилем. В случае злоупотреблений их легче отследить

## Присоединение к публичной чат-комнате

В списке слева в дереве *Публичные* есть список чат-комнат, передаваемых вашими друзьями. Дважды щёлкните по комнате или используйте контекстное меню, чтобы присоединиться к ней.

## Общение

Просто вводите текст для общения или нажимайте `shift + enter`, чтобы писать в несколько строк. Вы можете использовать [markdown](05a), отправлять или вставлять изображения прямо в сообщении 🖼️, отправлять ссылку 🖇️ на файл или отправлять стикеры.

## Приватные чат-комнаты

Приватные чат-комнаты доступны только людям, приглашённым в них. Вы можете создать такую комнату, а затем использовать кнопку *пригласить друга*, чтобы пригласить одного из своих друзей. Если вас пригласили в приватную комнату, появится запрос. Всё остальное идентично публичным комнатам.
