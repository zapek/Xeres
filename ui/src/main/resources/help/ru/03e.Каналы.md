# Каналы

Каналы — это способ распространения информации и файлов. Публиковать может только создатель канала.

## Создание

Нажмите кнопку создания канала 📁 вверху слева — вы сможете заполнить следующие поля:

- имя: название канала. Выберите описательное имя, но не волнуйтесь, его можно изменить впоследствии.
- описание: описание канала. Его можно изменить впоследствии.
- логотип: картинка для вашего канала. Его можно изменить впоследствии.

## Подписка на канал

Просто просмотрите дерево *Популярные* или *Другие* слева и дважды щёлкните или используйте контекстное меню на интересующем вас канале, чтобы присоединиться. Синхронизация может занять некоторое время в зависимости от вашего подключения.

## Публикация сообщения

Прежде всего, помните, что вы можете публиковать только в своём собственном канале. Для этого используйте кнопку *создать сообщение* ✏️. Запись в канале требует:

- заголовок: заголовок вашей записи
- миниатюра: миниатюра, отображаемая рядом с заголовком
- текст: по желанию текст, например, запись в блоге или описание
- файлы: один или несколько файлов, которые могут скачать пользователи, читающие запись
