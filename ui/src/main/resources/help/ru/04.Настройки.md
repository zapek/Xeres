# Настройки

Это окно содержит различные настройки Xeres.

- [Общие](04a): тема, проверка обновлений, автозапуск, запоминание учётных данных
- [Уведомления](04b): показывать подключения, широковещательные сообщения и обнаружение в LAN
- [Сеть](04c): NAT, LAN, DHT, UPNP
- [Передача](04d): папка для входящих
- [Медиа](04e): предпросмотр ссылок, подтверждение внешних URL
- [Звук](04f): звук для различных событий
- [Удалённый доступ](04g): удалённый доступ
