# Общие

## Тема

Задаёт тему приложения — светлую или тёмную, в зависимости от ваших предпочтений, зрения, экрана и т.д.

## Система

### Автоматически проверять обновления

Выполняет проверку GitHub API проекта Xeres раз в день, чтобы узнать, есть ли новый релиз.

🛡️ [Вопросы конфиденциальности](07a)

### Запоминать учётные данные

Если поддерживается, ОС будет использоваться для запоминания учётных данных для безопасной расшифровки данных. Запрос пароля не появится. Очень полезно, когда включена опция *Запуск при старте системы*.

🛡️ [Вопросы конфиденциальности](07h)

### Запуск при старте системы

Автоматически запускает Xeres при входе пользователя в систему. В настоящее время это реализовано только для обычной установки на Windows.
