# Уведомления

Показывает системное уведомление для следующих событий:

### Показывать подключения

Каждый раз, когда устанавливается соединение с другом.

### Показывать широковещательные сообщения

Каждый раз, когда друг отправляет широковещательное сообщение, то есть сообщение, которое отправляется всем его друзьям. Такие сообщения обычно отправляются при важных событиях, например, при объявлении о длительном простое или о проблеме.

К сожалению, этой функцией можно также злоупотреблять, поэтому иногда её стоит отключать.

### Показывать обнаружение

Каждый раз, когда кто-то находится в LAN и у него включено обнаружение в LAN. Вы также должны сами включить эту функцию.
