# Медиа

## Включить предпросмотр ссылок

Включает небольшой предпросмотр ссылок (миниатюра + описание) для большинства входящих ссылок от друзей, помеченных как полностью доверенные.

🚨 Будьте осторожны: предпросмотр ссылок создаётся на вашей стороне!

🛡️ [Вопросы конфиденциальности](07f)

Эта функция работает только в приватных чатах (прямых, не удалённых) и только с друзьями, у которых уровень доверия установлен как *полный* (по умолчанию — *неизвестный*).

По умолчанию выключена. Включайте её, если доверяете своим *полным* друзьям, предпочитаете видеть предпросмотр и в любом случае кликаете по большинству их ссылок.

## Включить подтверждение внешних URL

Когда включено, перед открытием внешних веб-сайтов будет появляться запрос на подтверждение. Это значение по умолчанию.
