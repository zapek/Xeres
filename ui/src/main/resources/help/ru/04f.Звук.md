# Звук

Эта настройка позволяет воспроизводить звук при некоторых событиях. Просто выберите короткий звуковой файл для каждого события.

Поддерживаемые медиаформаты:

- MP3
- MP4 (AAC)
- WAV
- AIFF

## Получено сообщение

Когда получено прямое или удалённое приватное сообщение. Пока окно находится в фокусе и активно, новые звуки не воспроизводятся.

## Упоминание

Когда кто-то упоминает вас в чат-комнате.

## Друг подключился

Когда друг подключается к вашему запущенному экземпляру.

## Загрузка завершена

Когда загрузка завершена.

## Звонок

Когда кто-то звонит вам через VoIP.
