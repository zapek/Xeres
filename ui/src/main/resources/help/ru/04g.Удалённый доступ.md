# Удалённый доступ

Эта настройка позволяет подключаться к запущенному экземпляру Xeres с помощью удалённого клиента (другого Xeres в режиме удалённого клиента или [Android-клиента](https://github.com/zapek/Xeres-Android/)).

Соединение шифруется (TLS 1.3 с самозаверяющим сертификатом). Android-клиент поддерживает закрепление сертификатов, что настоятельно рекомендуется для защиты от атак типа «человек посередине».

## Включено

Включает или выключает функцию.

## Порт

Порт для входящих подключений. Он должен быть доступен с вашего маршрутизатора.

## Задать через UPNP

Использует UPNP для проброса порта на вашем маршрутизаторе. UPNP должен быть включён в настройках сети.

## Имя пользователя

Это имя пользователя по умолчанию, его нельзя изменить.

## Пароль

Пароль. Хотя вы можете использовать пустой пароль (для тестирования или локальных подключений), делать это не рекомендуется. По умолчанию генерируется надёжный пароль, который редко требуется менять.
