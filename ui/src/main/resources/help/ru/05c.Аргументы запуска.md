# Аргументы запуска

При ручном запуске Xeres вы можете использовать следующие параметры командной строки. Это предназначено только для продвинутого использования и обычно не требуется.

- `--no-gui`: запуск без графического интерфейса. Можно использовать для запуска Xeres в headless-режиме. Используйте другой экземпляр с параметром `--remote-connect`, чтобы подключиться к нему.
- `--iconified`: запуск свёрнутым в трей. Это полезно для автозапуска.
- `--data-dir=<path>`: задаёт каталог данных. Именно здесь Xeres хранит все свои пользовательские файлы. Если вы хотите запустить несколько экземпляров, у каждого из них должен быть свой каталог данных.
- `--control-address=<host>`: задаёт адрес для привязки входящего удалённого доступа (по умолчанию только localhost).
- `--control-port=<port>`: задаёт порт управления для удалённого доступа. Это порт, к которому будет подключаться интерфейс. Если вы хотите запустить несколько экземпляров, у каждого из них должен быть свой порт управления, но Xeres попытается найти свободный слот автоматически (начиная с 6232), поэтому этот аргумент
  редко нужен.
- `--no-control-password`: не защищать адрес управления паролем. Пароль автоматически генерируется при первом запуске и виден в настройках. Его можно изменить или отключить.
- `--server-address=<host>`: задаёт локальный адрес для привязки (если не указан, привязывается ко всем интерфейсам).
- `--server-port=<port>`: задаёт локальный порт для входящих подключений. По умолчанию Xeres выбирает случайный порт и использует его постоянно для одного и того же экземпляра.
- `--fast-shutdown`: игнорировать корректную процедуру завершения. В основном полезно для тестирования, когда нужно быстро запускать/останавливать экземпляры Xeres. Для обычного использования не требуется.
- `--server-only`: принимать только входящие подключения, исходящие не устанавливать. В основном полезно для чат-серверов.
- `--remote-connect:<host>[:<port>]>`: запускается как UI-клиент и подключается к указанному узлу. Это также можно делать между машинами в LAN. Имейте в виду, что соединение не шифруется. Если вы хотите обойти это ограничение, используйте SSH-туннели.
- `--remote-password=<password>`: пароль для использования при удалённом подключении
- `--version`: выводит версию программного обеспечения
- `--help`: выводит справочное сообщение
