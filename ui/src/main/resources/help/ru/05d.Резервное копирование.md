# Резервное копирование данных

Все данные, которые использует Xeres, хранятся локально, поэтому время от времени следует делать их резервную копию.

Вот расположение папки, которую нужно копировать:

- Windows: `%APPDATA%\Xeres`
- Linux: `$HOME/.local/share/Xeres`
- macOS: `/Users/username/Library/Application Support/Xeres`
