# Конфиденциальность

Этот раздел предназначен для людей, заботящихся о конфиденциальности. В нём содержатся все технические детали о функциях, которые могут раскрыть вас в Интернете, и он поможет вам принять взвешенное решение.

- [Обновления](07a): автоматическая проверка обновлений
- [UPNP](07b): проброс входящих портов
- [Внешний DNS](07c): использование внешних DNS-сервисов для определения IP-адреса
- [Обнаружение в LAN](07d): широковещательная рассылка присутствия в LAN
- [DHT](07e): поиск друзей
- [Предпросмотр ссылок](07f): показ URL-адресов
- [Внешний URL](07g): предупреждения о внешних URL-адресах
- [Запоминать учётные данные](07h): не запрашивать пароль при запуске
