# Проверка обновлений

## Детали

Выполняется подключение к `https://api.github.com/repos/zapek/Xeres/releases/latest` с использованием типичного пользовательского агента *Chrome на Windows*, чтобы избежать отслеживания.

Полученная версия сравнивается локально, и если доступен более новый релиз, предлагается возможность его скачать. В случае согласия файл и его подпись скачиваются с GitHub тем же механизмом. Перед установкой выполняется проверка подписи с использованием встроенного открытого ключа из запущенного приложения. Если всё в
порядке, обновление можно установить.

Проверка выполняется ежедневно (со сдвигом во времени, чтобы усложнить профилирование).
