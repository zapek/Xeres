# Предпросмотр ссылок

## Детали

Предпросмотр ссылок создаётся на вашей стороне, то есть Xeres подключается к стороннему сайту, указанному в ссылке, и забирает с него данные. Сторонний сайт увидит входящее подключение от вас, даже если вы не нажимали на ссылку. Были приняты особые меры для использования «типичного» пользовательского агента, чтобы не
упрощать обнаружение Xeres.

## Риски

🟠 Высокий

Хотя стороннему веб-сайту будет сложно обнаружить, что вы используете Xeres, он может использовать это для составления профиля, связанного с вашим IP-адресом, в зависимости от того, какие URL-адреса дают вам ваши друзья.
