# Запоминать учётные данные

## Детали

При включении ОС будет использоваться для хранения учётных данных пароля базы данных, чтобы не требовалось запрашивать пароль профиля. Обратите внимание, что пароль вашего профиля не сохраняется, только пароль базы данных.

В настоящее время это работает только в Windows с помощью [API защиты данных](https://en.wikipedia.org/wiki/Data_Protection_API) (или DPAPI). Пароль базы данных будет зашифрован с использованием учётных данных вашей учётной записи Windows. Если данные Xeres будут перемещены на другую машину или ваша учётная запись
Windows будет удалена, расшифровка не удастся.

## Риски

🟢 Низкий

API шифрования ОС предназначен для шифрования конфиденциальных данных. Это перекладывает безопасность на вашу учётную запись ОС, что означает, что у неё должен быть надёжный пароль. Вредоносное ПО, работающее от имени вашей учётной записи, потенциально может расшифровать пароль.
