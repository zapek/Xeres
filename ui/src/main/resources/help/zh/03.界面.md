# 界面

Xeres 提供以下功能，可通过顶部的标签页访问。

- [首页](03a)：分享您的 Xeres ID 并添加好友
- [联系人](03b)：管理您网络中所有可用的联系人
- [聊天](03c)：在聊天室内实时讨论
- [论坛](03d)：参与同步讨论
- [频道](03e)：在频道中为您的订阅者发布文件、新闻或博客文章
- [公告板](03f)：在公告板中分享图片和链接
- [文件](03g)：匿名搜索、发送和接收文件

## 状态栏

在下方状态栏中，显示与您好友的连接数以及其他指示器。

### 链路

该 LED 显示您链路的质量。

### DHT

DHT LED 仅在启用 DHT 时出现（请参阅 [设置 / 网络](04c)）
