# 联系人

包含您的实例已知的所有联系人（身份和档案）的列表。联系人包括您的直接好友以及网络中的其他用户。

## 自己的联系人

在左上角，您可以点击自己的联系人，并通过在详细信息视图中点击图片的背景来更改您的头像。您还可以通过点击圆形的彩色 LED 来设置您的状态。

您还可以通过点击安全图标 🛡️ 来更改您的密码。

## 其他联系人

列表视图包含以下内容：

- 身份
- 档案
- 由档案支持的身份

通常，它会尽量合并可以合并的内容。使用筛选器来显示所有联系人或仅显示您的好友。

### 信任级别

在详细信息面板中，您可以设置您好友的信任：

- 未知：这是默认值。
- 永不：这是您还不太信任的好友。
- 边缘：基本可信。一个熟人，您稍有一点了解的人。
- 完全：完全信任，一位好朋友。

目前信任级别的功能有限。例如，如果启用了 [链接预览](04e)，它将只应用于完全信任的好友。

### 位置

底部的表格显示好友所有已知的位置。如果他有多个设备，您会在这里看到它们的列表。

### 评价

身份会获得您好友设定的声誉。您可以通过竖大拇指 👍 和竖大拇指朝下 👎 图标查看。如果一个身份收到的负面评价多于正面评价，它的可见度就会降低。

您可以对身份设定自己的评价：

- 😑 中立：这是默认值。
- 👍 积极：默认为您的好友设置，如果您希望某个身份绕过您好友的评价，可以使用该选项。
- 👎 负面：这将有效地将该身份从您的网络中屏蔽。

## 聊天

在身份上点击右键出现的上下文菜单（或右上角的聊天按钮 💬）允许启动直接聊天或远距离聊天。

### 直接聊天

这是与您直接连接的好友使用的聊天系统。它通常更快。

### 远距离聊天

这是与不是直接好友的身份使用的聊天系统。它使用 Turtle 隧道系统，因此更慢、可靠性较低，但完全匿名（即您的 IP 不会暴露给另一方）。
