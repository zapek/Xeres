# 聊天

聊天室是用于聊天的多人房间，有点像 [IRC](https://en.wikipedia.org/wiki/IRC)。

房间列表出现在左侧的列表视图中。一旦您加入某个房间，您就可以在其中聊天，同时也会将其提供给您的朋友。

有两种聊天室：

- 🌍 公开：没有限制
- 🔒 私有：仅对受邀成员可见

## 创建

按下左上角的创建聊天室按钮 💬，您将可以填写以下字段：

- 名称：房间的名称。请谨慎选择，因为之后无法更改
- 房间的主题：之后同样无法更改
- 可见性：公开或私有
- 安全：勾选以避免可能的垃圾信息。只有由档案签名的身份才允许进入。发生滥用时更容易追溯

## 加入公共聊天室

在左侧列表视图的 *公开* 树中，有您朋友转发的聊天室列表。双击其中一个或使用上下文菜单加入。

## 聊天

直接输入即可聊天，或按 `shift + enter` 换行书写。您可以使用 [Markdown](05a)、内联发送或粘贴图片 🖼️、发送文件链接 🖇️ 或发送贴纸。

## 私有聊天室

私有聊天室只对受邀成员可用。您可以创建一个，然后使用 *邀请好友* 按钮邀请您的某位好友。如果您被邀请加入私有房间，将会出现一个请求提示。其余的一切与公开房间相同。
