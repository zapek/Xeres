# 论坛

论坛是类似于 [新闻组](https://en.wikipedia.org/wiki/Usenet_newsgroup) 的公共留言板。

论坛与您的好友保持同步。您甚至可以在离线时写消息，稍后当连接恢复时它会自动同步。

## 创建

按下左上角的创建论坛按钮 📁，您将可以填写以下字段：

- 名称：论坛的名称。请选择一个有描述性的名称，不过别担心，您之后可以编辑它。
- 描述：论坛的描述。您之后可以编辑它。

## 订阅论坛

只需浏览左侧的 *热门* 或 *其他* 树，然后双击您感兴趣想加入的论坛，或在其上使用上下文菜单。同步可能需要一些时间，具体取决于您的网络连接状况。

## 发布消息

您可以使用 *创建消息* 按钮 ✏️ 发布消息。消息需要主题和正文，正文使用 [Markdown](05a) 编写。

您可以通过在列表中选择一条消息并在上下文菜单中选择 *回复* 来回复该消息。

您也可以编辑自己的消息，但请记住，之前的版本可能仍然对其他一些用户可见。
