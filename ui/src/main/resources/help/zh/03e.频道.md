# 频道

频道是分发信息和文件的一种方式。只有频道的创建者才能发帖。

## 创建

按下左上角的创建频道按钮 📁，您将可以填写以下字段：

- 名称：频道的名称。请选择一个有描述性的名称，不过别担心，您之后可以编辑它。
- 描述：频道的描述。您之后可以编辑它。
- 徽标：您频道的一张图片。您之后可以更改它。

## 订阅频道

只需浏览左侧的 *热门* 或 *其他* 树，然后双击您感兴趣想加入的频道，或在其上使用上下文菜单。同步可能需要一些时间，具体取决于您的网络连接状况。

## 发布消息

首先，请记住您只能在您自己的频道中发帖。为此，请使用 *创建消息* 按钮 ✏️。一条频道帖子需要：

- 标题：您的帖子标题
- 缩略图：显示在标题附近的缩略图
- 正文：可选地，一段文本，如博客文章或描述
- 文件：一个或多个可供阅读帖子的用户下载的文件
