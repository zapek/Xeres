# 公告板

公告板是发布图片和链接的一种方式，类似于在线留言板。

与频道不同，任何人都可以在公告板上发帖。

## 创建

按下左上角的创建公告板按钮 📁，您将可以填写以下字段：

- 名称：公告板的名称。请选择一个有描述性的名称，不过别担心，您之后可以编辑它。
- 描述：公告板的描述。您之后可以编辑它。
- 徽标：您公告板的一张图片。您之后可以更改它。

## 订阅公告板

只需浏览左侧的 *热门* 或 *其他* 树，然后双击您感兴趣想加入的公告板，或在其上使用上下文菜单。同步可能需要一些时间，具体取决于您的网络连接状况。

## 发布消息

使用 *创建消息* 按钮 ✏️。一条公告板帖子需要：

- 标题：您的帖子标题
- 正文：一段文本，如博客文章或描述
- 图片：帖子的图片。在大多数情况下分辨率是足够的。
- 链接：指向某个网站或内部内容的链接

只有标题是必需的。其余所有内容都是可选的。例如，您可以发布一个单独的链接、一个带描述的链接、一张单独的图片、一张带描述和链接的图片等……
