# 文件

文件功能允许共享、搜索、上传和下载文件。该系统使用 [Turtle 协议](https://en.wikipedia.org/wiki/Turtle_F2F)，这意味着所有文件操作都是匿名的。它们还会超越您的直接好友，一次下载可以使用多个来源。

左侧的标签页允许选择以下部分：

## 搜索

要搜索，请输入一个或多个搜索词。要显示结果文件，所有这些词都必须匹配。例如，搜索 *foo* 和 *bar* 将返回 *foobar* 和 *barfoo*，但不会返回 *foo*。

💡 要精确匹配，请在搜索词上加引号，例如 "foo bar" 将匹配 *foo bar*，但不会匹配 *bar foo*。

要下载文件，请在结果上使用上下文菜单并选择 *下载*。

## 下载

下载标签页显示进行中的下载及其进度。这可能需要一些时间，具体取决于来源的速度、可用来源的数量以及您的链路速度。一旦某个文件被标记为 *完成*，请使用上下文菜单对其进行操作。

## 上传

显示您当前正在上传的文件。

## 趋势

显示所有命中您节点的搜索。
