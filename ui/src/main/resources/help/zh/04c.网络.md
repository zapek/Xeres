# 网络

## NAT

NAT 指 [网络地址转换](https://en.wikipedia.org/wiki/Network_address_translation)。该机制允许路由器后面的许多设备使用路由器唯一的公共 IP 地址访问互联网。NAT 的问题在于，如果不借助一些帮助，入站连接无法正常工作。

### 外部 IP 和端口

如果正确检测到，外部 IP 和端口应显示在这里。

### 使用 UPNP

[通用即插即用（UPNP）](https://en.wikipedia.org/wiki/Universal_Plug_and_Play) 是一种运行在您路由器上的软件。如果启用，Xeres 将尝试使用它来改善来自您好友的入站连接。

建议在您自己的专用网络（家中）上启用它，在其他情况下禁用。在 Windows 上，如果设置为 *私有*（默认值），那么当您的网络使用私有配置文件时它将自动启用（请参阅 [如何在 Windows 上设置私有配置文件](https://search.brave.com/search?q=how+to+set+a+network+profile+on+windows)）。在其他平台上， *私有* 将默认为 *关闭*。

虽然 UPNP 因一些早期漏洞而名声不佳，但如果您的路由器足够新，您可以放心地在那里启用它。

## LAN

LAN 指 [局域网](https://en.wikipedia.org/wiki/Local_area_network)。也就是您路由器后面自己的网络。

### 内部 IP 和端口

内部 IP 和端口显示在这里。

### 使用 LAN 发现

LAN 发现是一种在本地网络上查找其他用户的系统。它有助于更新好友在局域网上的 IP，以便在他们更改 IP 时（例如 DHCP 租约过期）能够连接到他们。

如果在通知设置中启用，它还可以显示局域网中有人可用。

由于这些信息可能是敏感的，建议仅在您自己的专用网络（家中）上启用它，在其他情况下禁用。在 Windows 上，如果设置为 *私有*（默认值），那么当您的网络使用私有配置文件时它将自动启用（请参阅 [如何在 Windows 上设置私有配置文件](https://search.brave.com/search?q=how+to+set+a+network+profile+on+windows)）。在其他平台上， *私有* 将默认为
*关闭*。在其他一些场景下启用它可能是有用的（例如局域网派对）。

🛡️ [隐私影响](07d)

## DHT

[分布式哈希表](https://en.wikipedia.org/wiki/Distributed_hash_table) 是一种帮助两个节点在 IP 地址已更改或未知时相互找到的系统。它在动态环境中尤其有用（漫游、动态 IP 地址等）。

### 启用 DHT

启用或禁用 DHT。

何时启用 DHT：

- 您的 IP 地址经常变化
- 您使用笔记本电脑并且经常漫游/旅行
- 您有很多朋友也有这些习惯

何时不启用 DHT：

- 您有固定/稳定的 IP 地址和可用的 UPNP
- 您的带宽非常有限
- 您想保持低调。DHT 会向许多节点发送数据包

默认情况下，它是禁用的。

🛡️ [隐私影响](07e)

## 隐藏服务

此设置仅用于能够连接到使用隐藏服务的 Retroshare 客户端（[Tor](https://en.wikipedia.org/wiki/Tor) 或 [I2P](https://en.wikipedia.org/wiki/I2P)）。Xeres 本身不实现任何形式的隐藏服务，因此这不会使任何内容匿名化。

如果您想连接 Tor 或 I2P 用户，请分别将 Tor/I2P socks 代理配置为您正在运行的 Tor/I2P 安装。
