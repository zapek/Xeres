# 远程

此设置允许使用远程客户端（另一个处于远程客户端模式的 Xeres 或 [Android 客户端](https://github.com/zapek/Xeres-Android/)）连接到正在运行的 Xeres 实例。

连接是加密的（使用自签名证书的 TLS 1.3）。Android 客户端支持证书固定，强烈建议使用以避免中间人攻击。

## 启用

打开或关闭此功能。

## 端口

用于入站连接的端口。它需要能从您的路由器访问。

## 使用 UPNP 设置

使用 UPNP 在您的路由器上路由该端口。UPNP 需要在网络设置中启用。

## 用户名

这是默认用户名，无法更改。

## 密码

密码。虽然您可以使用空密码（用于测试或本地连接），但不建议这样做。默认会生成一个强密码，很少需要更改。
