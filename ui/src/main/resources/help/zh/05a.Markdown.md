# Markdown

这里是一份 Markdown 速查表：

## 基本语法

Markdown 在论坛和聊天中受支持（不过后者会忽略标题和水平分割线）。

### 标题

\# Header 1

\## Header 2

\### Header 3

（最多到 Header 6）

### 粗体

\*\*bold\*\* or \_\_bold\_\_

### 斜体

\*italic\* or \_italic\_

### 引用

\> blockquote

### 有序列表

1. First item
2. Second item
3. Third item

### 无序列表

\- First item  
\- Second item  
\- Third item

### 代码

\`code`

### 水平分割线

\---

### 链接

\[Markdown Guide](https://www.markdownguide.org)

### 图片

\![alt text]\(data:image/jpeg;base64,etc...)

## 扩展语法

### 围栏代码块

\`\`\`  
{  
"firstName": "John",  
"lastName": "Smith",  
"age": 25  
}  
\`\`\`

### 删除线

\~~Censored~~

### 表情符号

Woohoo! \:joy\:
