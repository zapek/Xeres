# 表情符号

可以使用别名快速显示某些表情符号。更推荐使用操作系统的键盘快捷键直接插入（例如在 Windows 上按 `Win`+`.`）。

### 最常用

:joy​: :joy:

:grin​: :grin:

:rofl​: :rofl:

:yum​: :yum:

:blush​: :blush:

:rage​: :rage:

:scream​: :scream:

:cry​: :cry:

:sob​: :sob:

:sick​: :sick:

:poop​: :poop:

:muscle​: :muscle:

:wave​: :wave:

:eyes​: :eyes:

:zzz​: :zzz:

:fire​: :fire:

:heart​: :heart:

:boom​: :boom:

### 国家/地区

:cc: （该国家/地区的互联网域名，例如 ch、fr 等……）
