# 启动参数

当手动运行 Xeres 时，您可以提供以下命令行选项。这仅用于高级用法，通常并不需要。

- `--no-gui`：无界面启动。可用于以无头模式运行 Xeres。使用另一个带有 `--remote-connect` 的实例连接到它。
- `--iconified`：最小化到托盘启动。这对自动启动很有用。
- `--data-dir=<path>`：指定数据目录。这是 Xeres 存储其所有用户文件的地方。如果要运行多个实例，它们各自需要有不同的数据目录。
- `--control-address=<host>`：指定要绑定以用于入站远程访问的地址（默认为仅 localhost）。
- `--control-port=<port>`：指定用于远程访问的控制端口。这是 UI 将连接的端口。如果要运行多个实例，它们各自需要有不同的控制端口，但 Xeres 将自动尝试找到一个空闲端口（从 6232 开始），因此很少需要这个参数。
- `--no-control-password`：不使用密码保护控制地址。密码在首次运行时自动生成，并可在设置中看到。可以更改或禁用。
- `--server-address=<host>`：指定要绑定的本地地址（如果未指定，则绑定到所有接口）。
- `--server-port=<port>`：指定要绑定以用于入站连接的本地端口。默认情况下，Xeres 选择一个随机端口并一直为同一实例使用它。
- `--fast-shutdown`：忽略正常的关闭流程。这主要用于测试时需要快速运行/关闭 Xeres 实例的情况。正常使用不需要。
- `--server-only`：只接受入站连接，不发起出站连接。主要用于聊天服务器。
- `--remote-connect:<host>[:<port>]`：以 UI 客户端启动并连接到指定节点。您也可以在局域网中跨机器执行此操作。请注意，连接不是加密的。如果您想克服这个限制，请使用 SSH 隧道。
- `--remote-password=<password>`：远程连接时使用的密码
- `--version`：打印软件的版本
- `--help`：打印帮助信息
