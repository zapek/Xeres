# 贴纸

贴纸是小图像或动画，有助于表达情感。它们可以在聊天消息中发送。

## 添加贴纸

贴纸集合放在子目录中，例如：

- `01.People`
- `02.Places`

可选的前缀 01、02 等可以控制贴纸集合在列表中出现的顺序。

每个集合包含各种贴纸，例如对于 `01.People` 目录：

- `01.Heike.png`
- `02.Juergen.png`
- `03.Antilove.png`

以此类推。它们也可以有可选的前缀用于排序，但像 `Heike.png` 这样的名称也可以。

## 文件格式

支持以下文件格式：

### 图像

- JPEG，最多 512x512 像素（`*.jpg`）
- PNG，最多 512x512 像素，支持透明度（`*.png`）
- WebP，最多 512x512 像素，支持透明度（`*.webp`）

### 动画

- TGS（`*.tgs`）
- Lottie（`*.lottie`、`*.json`）
