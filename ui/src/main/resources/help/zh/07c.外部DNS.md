# 使用外部 DNS

## 详情

Xeres 将尝试使用来自 [OpenDNS](https://en.wikipedia.org/wiki/OpenDNS) 或 [Akamai](https://en.wikipedia.org/wiki/Akamai_Technologies) 的随机外部 DNS。它将向它们的 DNS 服务器发送 UDP 数据包，以尝试解析外部 IP（`myip.opendns.com` 和 `whoami.akamai.net`）。

## 风险

🟢 低

这些服务将知道您想找出自己的公共 IP，但许多其他应用程序也会这样做，因为它们正是为此目的提供该服务的。由于该机制与普通解析器类似，它们无法知道您正在使用 Xeres。
