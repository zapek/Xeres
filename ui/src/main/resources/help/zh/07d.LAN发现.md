# LAN 发现

## 详情

LAN 发现会定期发送 UDP 广播数据包，以查明局域网中是否有其他 Xeres 客户端。它实现了与 [udp-discovery-cpp](https://github.com/truvorskameikin/udp-discovery-cpp) 项目中相同的协议。

以下信息会被广播：

- 一个 Xeres 应用程序标识符
- 您的 IP 地址和端口
- 您的档案指纹
- 您的位置标识符
- 您的档案名称

这些数据用于更新好友在局域网上的 IP，以便在其发生变化时（例如 DHCP 租约过期）能够连接到他们。如果在通知设置中启用，它还可以显示局域网中有人可用。

## 风险

🟢 在您自己的网络上低

🟠 在公共网络上高

建议在您自己的家庭网络上启用它，并在公共网络上禁用。公共网络可能会了解到您正在运行 Xeres，并且还会知道您档案的名称。
