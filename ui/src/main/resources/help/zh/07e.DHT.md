# DHT

## 详情

Xeres 使用 [Mainline DHT](https://en.wikipedia.org/wiki/Mainline_DHT)，这是 [BitTorrent](https://en.wikipedia.org/wiki/BitTorrent) 使用的 DHT。它会定期与其他随机节点发送和接收 UDP 数据包，以存储您位置 ID 的哈希。其他好友将请求该 ID，并最终找到您。请注意，您的 IP 地址本身永远不会存储在 DHT 中。

## 风险

🟡 中

虽然 DHT 本身被数百万种子用户使用，这使得通过这种方式难以检测到 Xeres 用户，但它会向许多节点发送 UDP 数据包，这不太隐蔽。
