# 记住凭据

## 详情

启用后，操作系统将用于存储数据库密码的凭据，这样就不需要提示输入配置文件密码。请注意，您的配置文件密码不会被存储，只有数据库的密码会被存储。

目前这仅在 Windows 上通过[数据保护 API](https://en.wikipedia.org/wiki/Data_Protection_API)（即 DPAPI）工作。数据库的密码将使用您的 Windows 帐户凭据进行加密。如果 Xeres 数据被移动到另一台机器，或者您的 Windows 帐户被删除，解密将失败。

## 风险

🟢 低

操作系统加密 API 专为加密敏感数据而设计。这将安全性委托给您的操作系统帐户，这意味着它应该有一个强密码。在您的用户帐户下运行的恶意软件可能会解密该密码。
